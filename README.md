# BlueStacks 5 特别装备升级助手

Windows / Python 3.11+，针对当前 PCR「道具一览 → 特别装备」金色五菱形装备布局。

## 全自动运行

本目录已安装好 `.venv`。可以直接双击 `run_auto.cmd`（退出后保留窗口，不进入 Python 的 `>>>` 交互模式），或运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 upgrade_equipment.py --fully-auto
```

`--fully-auto` 自动启用查找、执行、材料选择及提交，不再要求输入 YES：

1. 当前可见装备中寻找未满五星的候选，再核对右侧详情。
2. 满五星跳过；没有候选时向下滚动查询。
3. 上限不足时打开解锁页，只选择能识别为“三灰菱形 + 两个锁定菱形”的基础同名材料；不选已强化装备。逐件核对 Pt 恰好增加 1，够用后自动点击「解锁上限」。材料不足先滚动查找；确认材料列表到底仍不足时，自动关闭选材页、取消已选材料、跳过当前装备并继续下一件。
4. 验证上限已提高，再点击「强化 → 自动强化」。
5. 检查「特别装备强化确认」：**只有消耗列表仅含强化 Pt 时才自动确认**，不自动确认吞装备或购买；单件限 6000 Pt / 300000 玛那，且不能超过持有玛那。
6. 验证已到最高五星，再处理下一件。

上限解锁会永久消耗你允许作为材料的基础同名装备。强化会消耗强化 Pt 和玛那。脚本没有购买、分解或充值功能。视觉识别存在误差，首次使用请关注运行窗口；未知画面或异常会停止并保存现场。

## 使用条件与停止

- 开始时停在「道具一览 → 特别装备」详情页，关闭所有弹窗。
- 横屏 16:9，游戏画布宽至少 1000 像素；支持 Windows DPI 缩放。
- 运行中不要移动/缩放窗口、遮挡游戏、切换页面或操作装备。失去前台、窗口变动、页面未知即停止。
- 搜索从**当前滚动位置**向下进行，不包括上方；搜索全部筛选结果请先滚到顶部。
- 列表连续不变且滚动条到底才结束查询；滚动失败/达到安全次数只报停止，不声称搜完。
- 终端 `Ctrl+C` 停止；或按住 `Esc` / 将鼠标移到屏幕左上角，下一次截图或点击前停止。
- 确认材料列表到底仍不足时自动取消选材并跳过，不提交消耗。本次运行会记住同名、同图案且解锁需求不低于失败项的缺料情况，避免反复进入同一材料列表；上限已解锁完毕或需求更低的装备仍会正常处理。
- 无法确认材料列表到底、滚动失效、Pt 增量异常等仍停机并保留现场，不作为普通缺料跳过；重启前请关闭弹窗，回到详情页。
- 如果强化确认包含装备、Pt 不足、超出单件预算，停止，不尝试其他消耗方案。
- 当前只验证了金色五菱形布局。其他稀有度、特殊 EX 布局、模糊图标不当作可靠候选。

## 其他模式

```powershell
# 只读检查当前选中装备，不点击
.\.venv\Scripts\python.exe -X utf8 upgrade_equipment.py

# 自动查找并选中第一件未满星装备；必要时滚动，不升级
.\.venv\Scripts\python.exe -X utf8 upgrade_equipment.py --scan

# 辅助模式：自动选择解锁材料，但提交及强化需要人工关卡
.\.venv\Scripts\python.exe -X utf8 upgrade_equipment.py --scan --execute --auto-materials
```

参数：`--max-items 100`（最多处理件数）、`--max-scrolls 2000`（单次搜索最多滚动次数）、`--title "BlueStacks 5"`（精确窗口标题）、`--output runs`、`--repeat`（辅助模式手动选择下一件）。达到次数上限只停止，不报告整个背包完成。

辅助模式的人工关卡需要大写 `YES`，其他输入停止。全自动模式不使用人工输入。

## 安装与测试

其他机器安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

或：

```powershell
uv venv .venv --python 3.11
uv pip install --python .venv/Scripts/python.exe -r requirements.txt
```

测试：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

测试包含实际截图的满星/未强化/透明锁定菱形、候选查找、基础材料筛选、滚动到底与滚动失效区分、材料到底不足时取消并跳过及防止重复选择，以及仅 Pt 确认、其他装备/异常预算拒绝。

已修复两类透明菱形识别问题：
- 「贤王的耳饰」中心透出棕色图案：核对粉色菱形四条边和空心区域，不再要求中心接近白色。
- 「【行会】萨满的智慧」中心透出近灰色图案：未强化状态必须具有均匀灰色实心内部，不能仅凭中心几个像素判断；真正已解锁、带粉色边框的灰色实心菱形仍识别为未强化。缺失边框或证据不足仍停止。

已实测自动选两件基础材料、解锁上限，以及确认消耗 6000 Pt / 180000 玛那后验证五星。其他装备种类和长时间批处理仍可能遇到识别异常。诊断文件不会上传。

## 运行日志

每次命令行运行自动创建 `runs/日期-时间-PID/`（`--output` 可修改根目录）：

- `run.log`：终端输出的同步副本，包括开始/结束时间、PID、运行模式、选材/跳过/升级信息、停机原因、退出码及未预期异常的完整回溯。UTF-8 编码，每次写入立即刷新。
- `NNN-步骤.png` / `.json`：同一次运行的截图和 OCR 结果。

预览模式也记录日志；窗口初始化失败同样记录。发生问题可提供该次 `run.log` 和最后一张相关截图，无需手动复制终端内容。
